#### Priority Issues

- **[P0] Undefined CSS Token --color-primary-blue Breaking Focus Rings & Hover States**
  - **Why it matters:** Cripples the accessibility .skip-link, renders :focus-visible invisible across all elements, and causes 1.1:1 invisible white-on-gray hover text on skill pills.
  - **Fix:** Declare --color-primary-blue: var(--color-primary); in design-tokens.css and update :focus-visible to use --color-primary-focus.
  - **Suggested command:** $impeccable harden

- **[P1] Numerical Contradiction Across Marketing Surfaces (14 vs. 15 Skills)**
  - **Why it matters:** Headlines announce "The 14 Modular Skills" while catalog filters and JavaScript manifests list 15 skills, undermining mathematical rigor.
  - **Fix:** Uniformly standardize to "15 Modular Agent Skills" (or "14 Lifecycle Skills + 1 Socratic Orchestrator").
  - **Suggested command:** $impeccable clarify

- **[P1] Hero Section Visual Congestion & Broken Tile Rhythm**
  - **Why it matters:** The dark configurator container nested inside the white hero tile creates competing visual anchors and breaks the alternating full-bleed tile rhythm.
  - **Fix:** Move the configurator into its own dedicated full-bleed product-tile-dark section (#272729), letting the hero typography breathe.
  - **Suggested command:** $impeccable layout

- **[P2] Undismissable Sticky Install Bar Smothering Mobile Viewports**
  - **Why it matters:** Pinned 64px bottom bar combined with 96px top headers consumes 25% of mobile screens with no dismiss option.
  - **Fix:** Add an accessible × close button with sessionStorage persistence, and hide on viewports $\le 640\text{px}$.
  - **Suggested command:** $impeccable adapt

- **[P2] AI Template Tells: Neon Halos, Side-Tabs & Sub-Threshold Contrast**
  - **Why it matters:** 3px side-tab borders, green/blue glowing button box-shadows, and #7a7a7a contrast (3.9:1) dilute the Apple minimalist aesthetic.
  - **Fix:** Replace side-tabs with 1px hairlines, strip colored box-shadows, and darken --color-ink-muted-48 to #6e6e73.
  - **Suggested command:** $impeccable quieter
