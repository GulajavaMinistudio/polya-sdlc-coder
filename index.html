The Canonical 6-Phase Lifecycle

Over 90% of AI-generated bugs stem not from syntactic errors, but from premature coding on misunderstood requirements. Pólya SDLC Coder guarantees disciplined progression before writing application code.

PHASE 0

Discovery & Spikes

Explore problem feasibility, critique tech debt, and challenge premature premises.

/to-explore, /to-prd
PHASE 1

Understand & Specify

Deconstruct Unknown, Data, Condition into DTO contracts and Clean Architecture seams.

/to-spec, /to-clarify
PHASE 2

Devise Plan & Gate

Slice into vertical tracer bullets with Plan B contingencies and halt at The Pause Rule.

/to-plan ➔ 🛑 PAUSE
PHASE 3–6

Carry Out & Review

Clean code implementation, 5 SOLID audit, bisection bugfix, and Diátaxis documentation.

/to-code, /to-review
🛑 The Mandatory Pause Rule Gate

Unlike greedy autonomous agents that immediately write messy boilerplate, Pólya SDLC Coder enforces an unskippable governance gate after Phase 2 (Planning). The agent is strictly forbidden from writing functional application code until you review the vertical tracer bullets and explicitly grant approval.
